# Build a live model-authored semantic storyboard

## Purpose / Big Picture

Gate 1.8 proves the central product thesis that was still deliberately absent from Gate 1.7: a live language model can compose the order of a visual explanation while trusted code continues to own mathematical truth, geometry, presentation quality, interruption, and replay. A learner opens a storyboard studio, asks why two same-speed projectiles launched at 30 degrees and 60 degrees can land at the same range even though one rises higher, and immediately sees a deterministic visual anchor. One bounded provider stream then emits a short semantic program. Each complete semantic record becomes exactly one independently verified, visibly progressive checkpoint as soon as it is accepted.

The learner can request a different order, such as tracing the higher arc first or showing the range equation before motion, and the visible checkpoint order must change. The learner can interrupt after any accepted beat, ask a follow-up such as "Why are the ranges equal?", and continue from the exact living-board frontier without a wipe, repeated accepted content, or replaced stable objects. Replay is local and makes no model request.

This is not a universal animation language or a Manim replacement. It is a bounded falsification test for semantic composition. The first protocol is truthfully named `projectile_comparison_storyboard_v1`; later work may extract a shared cross-domain grammar only after a second domain proves which concepts are genuinely common.

In this plan, a **semantic storyboard** is the ordered list of atomic model-selected teaching beats. A **beat** is one `reveal`, `trace`, or `relate` record. An **anchor** is one server-authored, provider-free checkpoint that establishes the paired launch frame. A **frontier** is the exact accepted low-level scene, paired semantic state, certificate head, viewport, layout, and ordered beat ledger. A **catalog** is the server-owned closed vocabulary of concepts, trajectories, claims, valid evidence, and dependencies that the model may reference. An **accepted prefix** is the useful sequence of verified model beats retained when a later provider record is invalid, times out, or exceeds capacity.

## Surprises & Discoveries

- The generic certified browser runtime intentionally accepts `failed` or `declined` only before the first checkpoint of one generation. Combining an immediate Reflex checkpoint and fallible Director output into one generation would either weaken that invariant or require buffering the whole model response. Gate 1.8 therefore uses a provider-free anchor generation followed by a Director continuation generation from the committed anchor.
- The existing `CertifiedChoreographyStage` assumes a predetermined checkpoint total. A model-authored program has a bounded capacity but no honest promised length, so Gate 1.8 needs an additive open-frontier presentation mode rather than a fake progress denominator.
- Gate 1.7 already supplies the required low-level visual grammar: stable SVG objects, draw/fade/scale entrances, same-ID transforms and cross-fades, emphasis, camera focus, curved path tracing, atomic interruption settlement, and retained-DOM Replay. Gate 1.8 does not need a renderer rewrite or a new choreography version unless a concrete accepted storyboard proves V2 insufficient.
- Progressive model authoring creates a new valid terminal: a later malformed or timed-out record can follow an already verified prefix. That prefix is a product result, so the new wire must distinguish normal model completion from sanitized accepted-prefix completion without representing an unsafe tail as accepted or rolling back already presented checkpoints.
- A 30-to-45-second canonical capture would repeat the slow-pacing weakness already identified during visual review. Summing the locked cue durations for five model beats yields roughly 8.2 to 9.4 seconds across supported speeds, before the separately measured 1.05-second anchor. Gate 1.8 therefore treats 8 to 12 seconds as the complete five-model-beat visual target; evidence capture may include the anchor and surrounding interaction time but cannot relabel either as model-authored duration.
- The eight catalog effects are not simultaneously applicable: complementary comparisons have seven valid effects and non-complementary comparisons have six. A static ledger bound alone would permit a pointless paid call at a fully exhausted non-complementary frontier, so capacity is now checked against the bound problem before provider dispatch.
- Incrementally decoding a whole provider byte chunk would lose an earlier complete record if malformed UTF-8 appeared later in the same chunk. The Director parser therefore frames bytes first, strictly decodes each complete line, and exposes only schema-complete but not-yet-routed records as `complete_prefix`; verifier acceptance remains a later service decision.
- Declared SVG token rectangles are not evidence that KaTeX content fits: Chromium showed several formulas and values overflowing or clipping otherwise valid boxes. Gate 1.8 now measures every dynamic token across all nine problems with the actual KaTeX fonts in Chromium, and camera containment includes stroke extent plus a 12-pixel safety inset.
- Aborting a stream does not itself revoke its callbacks: abort listeners can fire synchronously and a cooperative runner can resolve normally. Stop must detach the producer authority first while retaining only the active playback token needed to settle the exact paint frontier.
- A reduced-motion assertion scoped only to the board first missed the animated logo in the surrounding storyboard shell, and the reduced-motion correction alone still allowed that animation in the full-motion interruption matrix. The interruption oracle watches the complete storyboard root, so the live studio now keeps its chrome static in every motion mode while preserving instructional motion inside the board; no timing sleep hides the distinction.
- A capture that observes Fast Refresh is not evidence for a single source revision even when every saved frame looks correct. The first concurrent capture was discarded and rerun unchanged; the artifact lifecycle therefore also fails closed on dirty sources and binds reports and media to one expected Git SHA.
- Cross-runtime fixture equality cannot use byte-identical decimal representations for recomputed geometry: Python-to-JSON-to-JavaScript arithmetic differed by at most 5.68e-14, while SVG line endpoints passed through browser Float32 storage before the DOM oracle rounded them. This is representation drift, not semantic drift, so the capture contract follows the prior gate's narrowly typed tolerance rather than weakening structural or categorical checks.
- A machine-valid normal-speed capture can still expose a product-level camera defect. The first official contact-sheet review showed equation fragments and prior labels in apparent letterbox space because an outer SVG clips to its physical viewport while `xMidYMid meet` projects a differently shaped logical `viewBox` into only part of it. Native `clientWidth` and `clientHeight` are also integer CSSOM values, so exact responsive matting uses fractional border geometry while the independent oracle derives the actual projection from `getScreenCTM()`.
- A closed output language can be structurally safe and still product-wrong: the first paid corpus produced forty canonical terminals yet answered three unsupported or ambiguous requests with true but irrelevant generic lessons. Request fidelity and abstention categories must be explicit model policy; catalog validity alone is not semantic relevance.
- A closed report schema is not evidence integrity by itself. Existing allowlisted fields can still be changed coherently unless the artifact is compared with the typed runtime facts that produced it; admission identity also matters because a local zero-call failure can leave a non-prefix set of paid reservations.
- Raw accepted records contain enough information for trusted code to derive frontier affordances, but requiring the model to reconstruct visible evidence and legal next records caused one round-to-round follow-up failure. The Director now receives that deterministic derivation as permissions rather than choices, so the model still owns the requested subset and order.
